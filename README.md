Este repositório reúne uma série de exercícios práticos desenvolvidos para consolidar conceitos essenciais de programação em **Python**. O projeto aborda desde lógica básica de repetição até manipulação inicial de dados com bibliotecas robustas e modularização de código através de funções.

## 🚀 O que você vai encontrar neste projeto?

O repositório está dividido em seções temáticas, cobrindo os seguintes tópicos:

1. **Estruturas de Repetição (`while` & `while True`)**:
   - Algoritmo de contagem incremental dinâmica utilizando limites definidos pelo usuário.
   - Sistema de validação de senha seguro com limite de 3 tentativas.
   - Menu iterativo de controle de fluxo de sistema.

2. **Estruturas de Dados (Listas e Dicionários)**:
   - **Atividade de Lista**: Sistema dinâmico para cadastrar novos carros e listar o inventário atualizado em tempo real.
   - **Gerenciamento de Contas**: Utilização de dicionários para criar, buscar e atualizar saldos de contas e usuários.

3. **Análise de Dados com Pandas**:
   - Introdução ao tratamento de dados tabulares.
   - Importação de arquivos `.csv`.
   - Uso de métodos analíticos fundamentais: `.info()`, `.describe()` e `display()` para visualização de sumários estatísticos.

4. **Modularização de Código (Funções & Lógica de Retorno)**:
   - Criação de métodos de boas-vindas personalizados com passagem de parâmetros.
   - **Conversor de Temperaturas**: Funções matemáticas para converter Celsius (°C) em Fahrenheit (°F) e Kelvin (K), com uso de `return` e inputs flutuantes.
